IronWallet – Non‑Custodial Multi‑Chain Crypto Wallet
IronWallet is a secure, non‑custodial multi‑chain cryptocurrency wallet designed for reliable asset storage, cross‑chain swaps, and seamless interaction with major blockchain networks. The project focuses on security, performance, and global accessibility, providing a lightweight client that works efficiently across a wide range of devices and network conditions.

Key Features
Non‑custodial architecture  
All private keys and seed phrases are generated and stored locally on the user’s device. No keys or sensitive data are ever transmitted to external servers.

Multi‑chain support  
Supports major networks including Bitcoin, Ethereum, Tron, Solana, BNB Smart Chain, Polygon, and others. Users can manage multiple assets in a unified interface.

Lightweight and optimized  
Designed to operate smoothly on low‑end devices and unstable connections, making the wallet accessible to users in emerging markets.

No registration or KYC  
The application does not require accounts, emails, or identity verification. Users retain full control over their assets at all times.

Real‑time market data  
Built‑in price tracking and asset monitoring for supported cryptocurrencies.

Security Model
Local key generation (BIP‑39)

Encrypted key storage on device

No custodial access, no backend key handling

Open, transparent transaction signing flow

Technology Stack
Native mobile applications (iOS / Android)

Blockchain interaction via RPC endpoints and public nodes

Cross‑chain swap integrations with decentralized liquidity protocols

Backend services for non‑sensitive metadata and analytics

Project Goals
IronWallet aims to provide a secure, globally accessible wallet that prioritizes user ownership, privacy, and reliability. The project continues to expand network support, improve performance, and integrate additional decentralized services.
